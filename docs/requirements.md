# 英语 MP3 精听 Android 产品需求

本文汇总 Android V1 和查词收藏 V2 的需求，并纳入已交付的逐词同步。本文所称「当前版本」为逐词同步测试版。

## 产品目标

让英语学习者将自己的播客、课程录音或有声书转成可回听的学习材料。在同一课程完成听音、定位句子和单词、查看释义、收藏以及回听原声。常用流程支持飞行模式。

## 功能需求

| 编号 | 功能 | 当前版本与验收条件 |
| --- | --- | --- |
| F01 | 导入本地音频 | 从系统文件选择器导入 MP3。课程库显示标题、时长和转写状态。重开应用后仍能通过保存的 URI 播放可访问的文件。 |
| F02 | 离线转写 | 导入后自动加入后台队列，显示进度。成功后生成英文字幕，失败时在课程详情显示原因。安装包内置英文模型，首次转写时在设备上解包。 |
| F03 | 导入 SRT | 支持带时间轴的本地 SRT，首行为英文，其余文本作为中文。解析到有效段落时替换该课程的字幕。 |
| F04 | 句级和词级联动 | 播放时高亮当前句和单词。点单词从其起始时间播放，点时间标签从句首播放。新转写使用 Whisper 的词级时间。缺少有效词级数据的旧字幕和 SRT 显示「词级估算」，并按句内时间估算。 |
| F05 | 离线查词 | 在收藏页输入英文单词，或在字幕长按菜单选词。内置词库命中时给出简明英英、中文释义和例句。独立查词还展示词性和来源。未收录时显示提示，用户仍可手动补充释义和收藏。 |
| F06 | 中文辅助理解 | 课程详情的「离线翻译」默认关闭，开关状态保存在本机。开启后显示已有中文并为缺失内容补充本地结果。预置句库未命中时显示带标签的词汇释义或未收录提示。关闭时隐藏中文。 |
| F07 | 收藏和回听 | 长按字幕可选收藏单词或整句。收藏页也可手动添加单词、短语或句子。保存前可编辑释义和例句。有关联课程及时间的条目从收藏列表点按后回到原音频位置。 |

### 学习流程

1. 导入音频，在课程库等待字幕就绪。
2. 打开课程播放，跟随高亮单词。需要重听时点单词或时间标签。
3. 遇到生词时长按字幕，从候选词打开预填词卡。保留例句或字幕语境，确认后保存。
4. 打开「收藏复习」回看双语释义。点带来源的条目回听，或通过「查词」补查其他词。

### 词卡内容

简明英英优先使用 A2–B1 难度的短句，避免循环释义。中文提供常见义，例句展示实际用法。离线查询以规范词形索引，目前支持大小写、弯引号和所有格归一化。当前词库为小规模内置词表，后续常用词库覆盖目标为约 3,000 词。

### 后续需求

- 精听控制增加播放变速、上一句和下一句、单句及 A–B 循环、盲听模式与后台播放控制。
- 转写增加显式取消、重试、字幕文本编辑及段落拆分合并，并验证长音频和低存储场景。
- 扩充离线词库，支持从字幕选取连续短语、上下文义项与例句。评估可下载的完整句译模型。
- 复习增加熟悉度、间隔复习、听写、语境填空和跟读录音。
- 增加本地学习数据导出及资源管理。在线词典、上下文讲解和跨设备备份作为可选能力，使用前需由用户主动启用。

## Android 实现

界面采用 Kotlin、XML 和 View Binding。Activity 持有 Media3 播放器并向课程详情提供播放位置。ViewModel 管理学习操作和 WorkManager 转写队列，Repository 协调 Room、文件元信息与本地词典。转写通过 Android MediaCodec 解码音频，再由 whisper.cpp JNI 生成英文字幕和时间戳。

| 数据 | 关键字段和用途 |
| --- | --- |
| `lessons` | 音频 URI、标题、时长、转写状态、进度和失败原因。 |
| `subtitle_segments` | 所属课程、句级开始和结束时间、英文、中文和可为空的 `wordTimings`。时间单位为毫秒。 |
| `words` | 以规范词形为主键，保存词性、简明英英、中文释义、例句和来源。 |
| `saved_entries` | 类型、收藏原文、双语释义、语境、课程 ID、回听起点与预留的下次复习时间。 |
| SharedPreferences | 保存离线翻译显示开关。 |

## 验收检查

- 飞行模式下导入本地英文 MP3，查看后台转写进度、播放结果并在重开应用后访问课程。
- 用新转写字幕验证点词跳播、连续高亮、停顿期间无单词高亮，以及从时间标签回到句首。
- 打开历史课程或导入 SRT，检查「词级估算」提示和按词定位。覆盖安装后复查原课程和收藏。
- 查询已收录和未收录的单词，检查双语释义、例句、未命中提示和保存操作。
- 长按字幕收藏单词或整句，再从「收藏复习」回听原音频。
- 切换离线翻译开关，检查预置句译、词汇释义标签和已有 SRT 中文的显示。

播放和查词应保持可操作。本地查词目标为 300 ms 内响应。正式发布前应补测长音频转写的耗时和资源使用，并复核依赖与模型的来源及许可。
